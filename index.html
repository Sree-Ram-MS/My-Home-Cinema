CastFlix is a small, single-file Python server that turns your phone into a Netflix-style media server for your home. Download a movie on your phone, open one address on your TV browser, and watch the original file — no copying to a pendrive, and no casting compression.

Quick Start ↓ Download server.py

What is this?

CastFlix started as a fix for a very specific setup: a Jio set-top box where third-party apps and sideloading do not work, but the TV browser does. So instead of installing an app on the TV, CastFlix serves a web page from your phone over your home Wi-Fi, and the TV browser plays it.

It is not a cloud service. Your local files are never uploaded anywhere. The phone only serves the page and the video to devices on the same Wi-Fi.

How it works

1

Put movies on your phone

Keep them in a folder, for example Movies/Avatar (2009)/Avatar (2009).mp4 and Series/Demo Show/Season 1/Demo Show S01E01.mp4. Add a poster.jpg next to a movie for a real poster.

2

Run one file on the same Wi-Fi

On Android with Termux, or on a PC, run python3 server.py --media ./media --port 8000. The server prints a TV address like http://192.168.1.10:8000.

3

Open it on the TV browser

Open that address on your TV. You get a Netflix-style grid, a hero banner, Continue Watching, series episode lists, subtitles, and seeking — all playing the original file directly, not a re-encoded cast.

Local vs Online — two different tabs

Local (Movies / Series)Online (CineLite tab)
SourceFiles on your phoneCineLite player, by TMDB / AniList ID, over the internet
Needs phone?Yes, phone on, on Wi-Fi, chargingNo, for playback — but the CastFlix page itself needs the phone unless you use the hosted Online page
QualityOriginal file qualityDepends on the external player and your internet
SearchSearch your own librarySearch by name with a free TMDB API key, saved only on the TV browser

The Online tab does not play your phone files. It is a separate way to watch titles you have not downloaded, using the CineLite embed player.

Features

🎬 Netflix-style UI

Hero banner, horizontal rows, glass header, 2:3 poster cards, hover play button, and gradient fallbacks when there is no poster.

📺 TV remote mode

Add ?tv=1 once, or tap TV mode. Arrows move, OK opens, Back closes, Left/Right skip 10 seconds, and the next episode plays automatically.

▶ Continue Watching

Progress is saved on the TV browser, with a Continue Watching row and resume on reopen. Local subtitles (.srt → WebVTT, .vtt) are supported.

🌐 Online tab

Movie / TV / Anime by ID, accent colours, quality preference, start/resume time, pause recommendations, recent titles, and search by name with a TMDB key.

⚠ Offline redirect

Tick the option in the Online tab and, if the phone server goes offline while the page is open, CastFlix counts down 10 seconds and opens cinelite.xyz. If you open the IP after the server is already down, bookmark that site directly instead — no page can redirect then.

🔒 Simple and local

Pure Python standard library — no pip packages. Optional PIN for the local library. MP4 + H.264 + AAC plays in almost every TV browser; MKV / HEVC / DTS files are flagged because some browsers refuse them.

Quick Start

On a PC (test first, 2 minutes)

python3 server.py --media ./media --port 8000
# Open http://127.0.0.1:8000 on the PC,
# then the LAN address printed by the server on the TV browser.

On an Android phone with Termux

# Install Termux from F-Droid, then in Termux:
pkg install python -y
termux-setup-storage
cd ~/storage/downloads/CastFlix
python3 server.py --media ~/storage/downloads/Movies --port 8000
# Open the printed http://192.168.x.x:8000 address on the TV.
# Keep the phone awake, on Wi-Fi, and charging while you watch.

Standalone Online page (no phone needed)

Upload online.html as index.html to a free static host — for example a GitHub repo with Pages enabled, Netlify Drop, or Cloudflare Pages — then open that hosted URL on the TV any time. It has only the Online tab; local files will not work from the hosted page.

Files in this repo

  • server.py — the whole CastFlix server and UI in one Python file. No pip packages needed.
  • online.html — the standalone Online-only page, for hosting with no phone server.
  • index.html — this page.
  • README.md — full setup, folder layout, and version history.

Tip: if a file will not play on the TV, try it as MP4 first. MKV files often only need remuxing, not re-encoding: ffmpeg -i input.mkv -c copy output.mp4
